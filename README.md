# ☕ CupHub — Mobile Coffee Ordering Application

A modern and sleek Android application built with **Jetpack Compose** following **Clean Architecture** principles. CupHub provides a seamless coffee ordering experience with online payment integration and full feature customization.

## 🛠 Tech Stack & Architecture

- **UI Framework:** Jetpack Compose (Declarative UI)
- **Architecture:** Clean Architecture (Data, Domain, Presentation layers)
- **Design Pattern:** MVVM (Model-View-ViewModel) with Unidirectional Data Flow (UDF)
- **Payment Integration:** Stripe / Payment Gateway Integration
- **Asynchronous Operations:** Kotlin Coroutines & Flow
- **Dependency Injection:** Hilt
